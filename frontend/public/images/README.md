# Project Images

Place your project images here with the following names:

- `drivehub.jpg` - DriveHub Car Rental System
- `product-lifecycle.jpg` - Product Life Cycle Management
- `helpdesk-mini.jpg` - HelpDesk Mini Support System
- `keylogger-detection.jpg` - Keylogger Detection Security Tool

## Image Specifications

- **Format:** JPG or PNG
- **Recommended size:** 1200x800px (landscape)
- **Max file size:** 500KB (optimized)
- **Style:** Professional, modern, technology-focused

## Sources

Use royalty-free images from:
- Unsplash (https://unsplash.com)
- Pexels (https://pexels.com)

See PROJECT_IMAGES_GUIDE.md in the root directory for detailed guidance.

## Fallback

If images are not present, the portfolio will show gradient placeholders with the first letter of each project name.
